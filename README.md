# CapChar — 实时人体姿态捕捉与状态分析

**CapChar** 是一款 Windows 桌面软件，基于 MediaPipe 姿态估计模型，对摄像头或电脑屏幕画面进行**实时人体骨骼捕捉**，并进一步分析每个人的动作状态（站立、行走、奔跑、跳跃、倒地等），以深色主题界面实时呈现骨架、轨迹与统计数据。

- 版本：v1.0.0
- 平台：Windows（提供免安装绿色版 exe）
- 技术栈：Python 3.13 · Tkinter · OpenCV · mss · MediaPipe Tasks (PoseLandmarker)

## 核心功能

| 功能 | 说明 |
| --- | --- |   
| 双输入源 | 支持**摄像头**与**屏幕画面**两种输入，可用于真人捕捉或分析视频/直播画面 |
| 真实设备名 | 自动枚举 DirectShow 摄像头名称（如 "OBS Virtual Camera"）与显示器型号、分辨率、主屏标记 |
| 多人姿态捕捉 | 33 个关键点的骨骼检测，支持多人同框，各自独立绘制骨架与标签 |
| 状态分析 | 识别站立 / 行走 / 奔跑 / 坐姿 / 蹲下 / 跳跃 / 弯腰 / 倒地 / 静止等状态，按颜色区分 |
| 骨架与轨迹 | 实时叠加骨架连线、边界框、状态标签，可开关运动轨迹拖尾 |
| 流畅度档位 | 5 档性能预设（极致画质 → 极致流畅），动态权衡检测分辨率、人数上限与检测频率 |
| 实时统计 | FPS、检测人数、各状态分布计数实时刷新 |

## 流畅度档位

## 架构与性能设计

```
摄像头 / 屏幕 ──► 采集线程 ──► 最新帧缓冲 ──► UI 渲染（~33 fps）
                     │
                     └─► 异步检测线程（MediaPipe PoseLandmarker）──► 状态分析 ──► 骨架/标签绘制
```

- **采集与渲染解耦**：采集线程独立运行，UI 只取最新一帧，画面卡顿不影响采集
- **异步检测**：检测在独立线程执行并丢帧追赶，绝不阻塞界面
- **检测器复用**：停止后再次开启无需重新加载模型，秒级重启
- **后台化**：设备扫描、模型初始化、资源释放全部在后台线程完成，界面始终可响应
- **渲染优化**：Canvas 图像项复用、统计文本变化才刷新、 mediapipe 延迟加载

## 快速开始

### 方式一：直接运行绿色版（推荐）

1. 解压并进入 `dist/CapChar` 文件夹（约 300 MB，需整体拷贝）
2. 双击 `CapChar.exe`
3. 选择输入方式与设备，点击「开启」

### 方式二：源码运行

```bash
pip install -r requirements.txt
python main.py
```

### 自行打包

```bash
build.bat        # 调用 PyInstaller，产物在 dist/CapChar
```

## 项目结构

```
CapChar/
├── main.py               # 程序入口：线程编排、渲染循环
├── ui.py                 # 深色主题界面
├── detector.py           # MediaPipe 姿态检测与状态分析
├── source_manager.py     # 摄像头 / 屏幕采集与设备枚举
├── frame_renderer.py     # 骨架、轨迹、标签绘制
├── config.py             # 全局配置（主题 / 档位 / 阈值）
├── launcher.py           # 依赖检查启动器（源码运行用）
├── pose_landmarker.task  # 姿态检测模型（lite, 5.7 MB）
├── CapChar.spec          # PyInstaller 打包配置
└── build.bat             # 一键打包脚本
```

## 已知限制

- 状态判定基于规则阈值，复杂动作（如坐姿与静止的区分、跳跃）识别精度有限
- 检测置信度等参数在运行中修改需重新开启后生效
- 屏幕采集帧率受系统 GDI 限制，1080p 下约 15–30 fps
